# Retouch Clicky

Простой локальный редактор для быстрой ретуши фото в браузере.

## Что умеет

- Загрузка JPG, PNG и WebP.
- Перемещение фото и зум.
- Инструменты: двигать, волшебная кисть, заплатка, штамп, смягчение.
- Настройки кисти: размер, мягкость, сила.
- Тон, баланс белого, насыщенность и выборочная коррекция цвета.
- Зерно: светлое, темное, размер, прозрачность.
- Экспорт результата в PNG.

## Как открыть

Открой `index.html` в браузере. Все работает локально, фото никуда не отправляются.
